# Справочник слоёв: что сервис понимает и как дописать новое

Классификация идёт по цепочке, каждый следующий способ включается только
для того, что не распознал предыдущий:

1. **Ручное назначение** — страница «Слои чертежа». Главнее всего остального.
2. **Правила по имени слоя** — таблица ниже.
3. **Имя внешней ссылки** — суффикс файла выгрузки Мосгоргеотреста.
4. **Цвет линии** — стандарт условных обозначений топоплана.
5. **Форма объектов** — круги кроны, колодцев, опор.
6. **Контекст** — соседство с распознанными линиями, слова в именах
   этого же чертежа, подписи у линий.
7. **Локальная модель** — необязательна, предложения подтверждает человек.

---

## Имена файлов выгрузки Мосгоргеотреста

В именах внешних ссылок зашит тип файла. Это работает на любой улице:

| Суффикс | Что за файл | Класс по умолчанию |
|---|---|---|
| `tp` | топоплан: ситуация, здания, ограды, крыльца | по имени слоя |
| `up` | подземные коммуникации | подземная сеть |
| `pp` | проектируемые сети | подземная сеть |
| `brd` | рамки листов заказа | оформление |
| `kl` | линии градостроительного регулирования | оформление |

Пример: `output[1-12]_3_ДЖКХ-24_03233up$0$Подземные коммуникации` —
вид сети не назван, но суффикс `up` говорит, что это подземная
коммуникация, и отступ берётся наибольший из трубопроводных.

## Коды сетей на топоплане

| Код | Сеть | | Код | Сеть |
|---|---|---|---|---|
| В1, В2 | водопровод, водовод | | Т1, Т2 | теплосеть |
| К1 | канализация хозбытовая | | Г | газопровод |
| К2 | водосток, ливневая | | КЛС | кабель линии связи |
| ДК | дождеприёмный колодец | | КЭ, КЛ | кабель электрический |

## Кодировка покрытий в проектных слоях

`ДВ_ПП_<тип>_У|Р_<ТР|ПЧ>`: У — устройство, Р — ремонт, ТР — тротуар,
ПЧ — проезжая часть, АБ — асфальтобетон, ПЛ — плитка.

Оборот «за счёт» указывает, что было раньше, а значим результат:
`Газон_У за счет АБ_ТР` — это газон на месте разобранного тротуара,
`Тип3_У_ПЧ за счет газона` — наоборот, проезжая часть вместо газона.

## Как добавить новую улицу

1. Прогоните чертёж. На странице результата — блок «Как распознан чертёж»
   и список крупнейших нераспознанных слоёв.
2. Откройте «Слои чертежа»: сверху написано, скольким слоям нужно
   назначить класс, чтобы нераспознанного стало меньше 10%. Они помечены
   оранжевым и стоят первыми.
3. Если имя слоя непонятно, откройте «Разметка моделью» — модель
   предложит класс с пояснением, вы подтвердите.
4. Назначенное сохраняется в `config/layer_map.yaml` и работает во всех
   чертежах, где встретится слой с таким же именем.
5. Если слой встречается у многих проектировщиков, допишите правило в
   `src/layers.py` — тогда оно заработает без ручного назначения.

## Что не является объектом

- **АКР** — альбом конструктивных решений: поперечные профили рядом с
  планом. В нём свои «Газон» и «Граница работ», поэтому весь раздел —
  оформление. **ПОР** (рельеф: горизонтали, отметки, пикеты) и **ОФР**
  (оформление) — тоже.
- **«Освещённость»** — расчёт освещённости сеткой цифр, а не опоры.
- **«Демонтаж»** — объекта к моменту посадки не будет: класс «не учитывать».
- **«сущ.»** само по себе деревом не делает: «Водопровод сущ.» — водопровод,
  «Сущ. опора» — опора.
- Трубы в разделах **ЭН/ЭС** — футляры кабелей, это кабель, а не водопровод.

## Слабые способы не расширяют зону посадки

Цвет, форма, соседство, подписи, обученная модель имён и локальная модель
могут назначить только препятствие или оформление. Газон, границу работ и
«не учитывать» назначает человек или правило по имени: ошибка в них ставит
деревья на асфальт. Отклонённые предложения видны в сводке расчёта.

Контуры типов покрытий (`ГП_контр_тип6`) получают класс по номеру типа из
того же чертежа: `ДВ_ПП_ДО_Тип6_…_трот` — тротуар, `…_Тип1_…_ПЧ` — проезжая
часть.

## Проверка

    python tests/test_layers.py      имена слоёв из реальных чертежей
    python src/train_layers.py       модель имён: выборка сверяется с правилами
    python src/eval_llm.py           точность локальной модели на выборке

## Чего распознавание не умеет

Слой `0` — общий слой AutoCAD, куда попадает всё подряд. Осмысленного
имени у него нет по определению. Помогают только цвет объектов, их форма
и соседство с распознанными линиями. Если и это не сработало, слой
назначается вручную или чертёж отдаётся с замечанием.
